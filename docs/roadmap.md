# Roadmap

## Phase 0 — MVP (current)

- Tauri window + Chessground board
- Legal moves via Shakmaty
- Status: turn, check, mate, stalemate
- New game + promotion UI
- Engine module stub only

## Phase 1 — Engine manager

- Download and install UCI engines into app data
- List / enable / remove engines
- Spawn process and speak UCI
- Multi-engine support (Stockfish and others)

## Phase 2 — Cross-platform

- Windows and macOS packaging
- Platform-specific engine binaries in the registry

## Phase 3 — Analysis & history

- Live analysis panel
- Move history / navigation
- Optional PGN import/export and local game storage
